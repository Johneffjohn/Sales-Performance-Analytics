#  Sales Performance Analytics-PowerBI

##  Project Overview
This project analyzes sales performance across customers, products, and geographic regions using Power BI.

##  Business Objectives
- Identify top-performing products
- Analyze customer contribution
- Evaluate regional performance
- Monitor sales trends over time

##  Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling
- Excel

##  Dashboard Pages
Executive Summary
- Total Sales
- Total Profit
- YTD Sales
- YoY Growth
Product Analysis
- Top Products
- Product Profitability
- Product Ranking
Customer Analysis
- Top Customers
- Customer Contribution
Geographic Analysis
- Sales by Country
- Sales by State
- Regional Performance

##  Key Insights
- Identified highest-performing products and customers
- Analyzed regional sales performance
- Implemented time intelligence metrics
- Developed KPI-driven dashboards
